# FibonacciLibrary — тестовое задание №0

Требуется .NET 10 SDK. Откройте `FibonacciLibrary.sln` в IDE.
Реализуйте метод `NumberUtils.Fibonacci` в проекте `MathLibrary`.

Из корня репозитория выполните:

```bash
dotnet restore
dotnet build
dotnet test
```

До реализации метода все семь тестовых случаев ожидаемо не проходят.
После реализации все тесты должны пройти. Не изменяйте тесты.
Выполните commit и push в выданный репозиторий Gitea.

Для восстановления пакетов необходим доступ к NuGet или предварительно заполненный локальный кэш.
